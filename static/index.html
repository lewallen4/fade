Endpoints
POST /audit/free One-line diagnosis. No auth. No payment. Send {"content": "..."}
POST /checkout Get DOGE payment details. Send {"tier": "full"|"agent", "content": "..."}. Returns address, amount_doge, and session_id.
POST /audit/full Full prompt audit ($1). Send {"content": "...", "session_id": "..."} after payment.
POST /audit/agent Full agent audit ($3). Send {"content": "...", "session_id": "..."} after payment.
GET /.well-known/agent.json Machine-readable agent manifest. Capability declaration for agent discovery.
GET /constitution The AI Constitution — ethical framework Fade operates under. Worth reading.
